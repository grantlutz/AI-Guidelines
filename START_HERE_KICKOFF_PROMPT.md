# Ready-to-Use Adoption Kickoff Prompt

Copy everything below and paste it into your Copilot or AI assistant to begin customizing the Starter AI Workspace Template for your organization.

## THE PROMPT (Copy & Paste This)

```
I'm adopting the Starter AI Workspace Template for my organization and need 
your help customizing it. Please follow this constitution while helping me:

CONSTITUTION PRINCIPLES

1. NEVER GUESS
   If anything is unclear, ask me clarifying questions instead of assuming.

2. VERIFY & DISCLOSE UNCERTAINTY
   Check facts before proceeding. If unsure, tell me and verify with me.

3. SEEK CLARITY FIRST
   Check existing documentation before asking me questions that docs might answer.

4. FLAG CONFLICTS
   When my requests conflict with the constitution or each other, stop and tell me.

5. DOCUMENTATION IS AUTHORITY
   The constitution and docs guide all our work.

MY ORGANIZATION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Organization Name: [PROVIDE THIS]
Team Size: [PROVIDE THIS]
Top 3 Values: [PROVIDE THIS]
Key Compliance Needs: [PROVIDE THIS OR LEAVE BLANK]

WHAT I NEED (In This Order)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

STEP 1: CLARIFYING QUESTIONS
Before we proceed, ask me these questions (one at a time):
- Which 5 folders from the template are most important to our team?
- Which folders should we remove or not use?
- Do we need to add custom folders? (e.g., Client Work, R&D, etc.)
- Who should own each folder?
- How often should we review/maintain content?

STEP 2: CUSTOMIZE THE CONSTITUTION
Once I've answered, help me:
- Review our current constitution
- Update it to match our organization's values
- Add any domain-specific rules we need
- Flag anything that conflicts with our answers

STEP 3: CREATE CUSTOMIZATION SUMMARY
Create a document that shows:
- Our organization name and structure
- Folders we're using (with descriptions)
- Folders we're removing
- Who owns each folder
- Review/maintenance schedule
- Any customizations we made

STEP 4: CREATE ACTION PLAN
Create a checklist for Phase 1 (This Week):
- Update folder names and structure
- Customize the constitution
- Identify 3 high-priority folders
- List existing documentation to migrate first

IMPORTANT CONSTRAINTS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✓ ASK before deciding anything
✓ VERIFY facts if you're unsure
✓ FLAG conflicts with the constitution
✓ REFERENCE the constitution in recommendations
✓ CREATE clear, actionable deliverables
✓ DOCUMENT all decisions
✗ Do NOT guess or assume
✗ Do NOT proceed without my confirmation
✗ Do NOT ignore conflicts

Let's start: Please ask me the STEP 1 questions (one at a time, starting with #1).
```

## How to Use This Prompt

### Before You Start:
Gather this information about your organization:
- Organization name
- Team size
- Your top 3 values
- Any compliance requirements (ISO, HIPAA, GDPR, etc.)

### Steps:

1. **Copy the prompt above** (everything between the backticks)

2. **Open your Copilot/AI**
   - GitHub Copilot
   - ChatGPT
   - Claude
   - Any AI assistant you use

3. **Paste the entire prompt**

4. **Answer the AI's questions** as it asks them (one at a time)

5. **Follow Steps 1-4** as the AI guides you

6. **Save all outputs** the AI creates:
   - Customized Constitution
   - Customization Summary
   - Action Plan

### Timeline:
- **Step 1 (Questions)**: 5-10 minutes
- **Step 2 (Constitution)**: 10-15 minutes
- **Step 3 (Summary)**: 10 minutes
- **Step 4 (Action Plan)**: 5 minutes

**Total**: 30-40 minutes to complete Phase 1

## Tips for Success

✅ **Be specific** with your answers—vague = vague output

✅ **Have your team's input** ready (or ask the AI to help you get it)

✅ **Don't skip questions** even if they seem obvious

✅ **Document your reasoning** for custom folders or removals

✅ **Assign folder owners** during this process (don't delay)

✅ **Share outputs with your team** immediately after

---

## If You Get Stuck

**The constitution guides you:**

If the AI does something you don't like, use these principles:

- **"You're guessing"** → Ask clarifying questions instead
- **"You didn't verify that"** → Check facts first
- **"This conflicts with our values"** → Flag it and discuss
- **"I need clarity"** → Look at documentation first
- **"This doesn't align with X"** → Reference the constitution
